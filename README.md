# Оболочка «Графа идеи» (idea-graph-shell)

Локальная веб-страница поверх `idea-graph-engine`: экран проектов, **линейная цепочка шагов слева и граф справа**, вкладки «Банк»
(знания проекта) и «Настройки». Весь HTTP и интерфейс; логики агентов здесь нет.

```
idea-graph                 # экран проектов в браузере
idea-graph папка-проекта   # сразу открыть проект
idea-graph --port 8770     # другой порт
```

Что внутри: `server.py` — HTTP и статические файлы; `static/js/steps.js` — шаги слева; `graph.js`, `canvas.js` — граф;
`diagrams.js` — UML-диаграммы в SVG (последовательности и вариантов использования); `bank.js` — банк; `settings.js` — настройки;
`app.js` — вкладки и опрос состояния.

Граф только показывает результат: карточки создаются на шагах слева (принять, отклонить, удалить, написать своё).

## Установка и тесты

```
pip install -e ".[test]"        # нужны idea-graph-core и idea-graph-engine
python -m pytest
```
