# Оболочка «Графа идеи» (idea-graph-shell)

Локальная веб-страница поверх `idea-graph-engine`: стартовый экран проектов, холст с карточками и тремя крупными этапами, панель помощника («Что дальше», кнопки этапа, вопросы агента), банк, ресурсы, вкладка «Документ», настройки. Весь HTTP и интерфейс; логики агентов здесь нет.

```
idea-graph                 # экран проектов в браузере
idea-graph папка-проекта   # сразу открыть проект
idea-graph --packages      # какие пакеты установлены
idea-graph --port 8770     # другой порт
```

Что внутри: `server.py` — HTTP и статические файлы; `static/js/map.js` — карта этапа; `graph.js`, `canvas.js` — холст;
`dock.js` — чат и вопросы; `settings.js` — настройки. Всё этапозависимое (виды карточек, поля, диаграммы, банки) интерфейс берёт из
деклараций пакетов-этапов и подгружает их JS-модули (`/pkg/<пакет>/static/…`).

## Установка и тесты

```
pip install -e ".[test]"        # нужны idea-graph-core и idea-graph-engine
python -m pytest
```
